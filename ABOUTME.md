### About This Project

Built this Knowledge Q&A app to explore how RAG (Retrieval-Augmented Generation) works in practice. The idea was to keep it simple — no heavy frameworks, no external vector databases — just Node.js, SQLite, and the Gemini API doing all the heavy lifting.

Things I'm most happy with:
- The text extraction pipeline that handles text, PDFs, and images through one interface
- Getting sentence-aware chunking with overlap working properly
- The dark glassmorphism UI (spent more time on CSS than I'd like to admit)
